# Competition Analysis Profile

本文件定义竞品分析的长期偏好。Orchestrator 启动时自动读取并注入 Prompt。

## 报告风格

- 语言：中文简体，专业客观，避免夸张营销用语
- 结论必须有来源标注 `[n]`，不接受模糊引用
- 数据指标优先使用表格呈现，定性分析使用结构化段落

## 分析维度默认权重

当用户 query 未明确指定时，使用以下默认权重：

- features（功能特性）：0.7
- pricing（定价策略）：0.7
- users（用户与市场）：0.5
- market（竞争格局）：0.5

## 来源可信度

- 官方文档 / 财报 → strong（≥0.7）
- 知名科技媒体 / G2 / ProductHunt → moderate（≥0.4）
- 个人博客 / 论坛帖子 / 未验证来源 → weak（<0.4）
- 禁止引用"据传闻""据说""可能大概"等模糊表述
- 交叉验证要求：同产品同维度至少 2 个独立域名来源

## QA 门槛

- 覆盖率目标：≥ 70%
- 交叉验证率目标：≥ 30%
- 单轮 evidence strength weak 占比 > 50% → 触发定向返工
- 同一 gap 连续出现 3 轮 → 降级为 minor，不再打回

## 行业专属维度

SaaS 行业额外关注：PLG 策略、定价模型复杂度、API 开放度、集成生态
DevTools 行业额外关注：文档质量、社区活跃度、CLI 体验、SDK 覆盖
硬件行业额外关注：供应链、制程工艺、功耗性能比、认证合规
